# 数字怀仁 · 一座城的记忆长廊

「数字怀仁」是一个以数字化手段展示山西省怀仁市历史、地理、人文、人物等全方位信息的综合性文化网站，旨在传承地方文化、服务公众查阅、助力文旅发展。

> “怀想仁人”之名，始于辽代；千年古县，2018 年撤县设市。

## 项目简介

以**县志文献为骨、地理人文为脉**，将怀仁市的千年沿革、山水风貌、民俗遗产、人物传奇、影像记忆与古今地图串联起来，让历史可读、山水可游、人物可近。

## 功能板块

| 板块 | 说明 |
| --- | --- |
| 县志文献（`zhixian.html`） | 古籍县志高清数字化、新编县志全文与校注成果，附原文影像浏览与全文检索 |
| 地理风貌（`dili.html`） | 自然地理、行政区划、生态资源——“一城两山三湖七河百村”的山水格局 |
| 人文历史（`renwen.html`） | 千年沿革、国家非遗怀仁旺火、鹅毛口遗址与金沙滩古战场的故事 |
| 人物长廊（`renwu.html`） | 从元代平章政事赵璧到刻瓷大师麻渊，一方人物传奇 |
| 影像怀仁（`yingxiang.html`） | 历史老照片、航拍风光、旺火秧歌民俗视频与陶瓷工艺纪录片 |
| 数字地图（`ditu.html`） | 标注主要景点遗址的电子地图，与历史地图 |
|  交流反馈（`hudong.html`） | 在线留言与投稿、怀仁文化论坛、知识问答 |

## 技术栈

纯静态站点，无构建步骤，无需后端即可运行：

- **HTML5 + CSS3**（`css/style.css`，含响应式布局、滚动显现动画）
- **原生 JavaScript**（`js/main.js`，移动端导航、返回顶部、FAQ 手风琴、地图悬浮提示、表单提交等）
- **Google Fonts**（Noto Sans SC / Noto Serif SC）

## 本地运行

项目为纯静态网页，直接用浏览器打开任意页面即可：

```bash
# 方法一：双击 index.html 直接打开

# 方法二：本地静态服务器（推荐，可正常加载字体与资源）
python -m http.server 8000
# 或
npx serve .
# 然后访问 http://localhost:8000
```

## 交互说明

- **移动端导航**：点击右上角汉堡按钮展开菜单
- **滚动显现**：页面元素随滚动渐显（`IntersectionObserver`）
- **数字地图**：鼠标悬浮地图标注点查看景点/遗址简介
- **留言表单**：留言/投稿表单通过 `mailto:` 调起本地邮件客户端发送，演示表单为前端模拟提交
- **回到顶部**：滚动超过 600px 后显示
